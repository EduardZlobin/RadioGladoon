# Radio Gladoon

Тёмный радиосайт с бесконечным циклом:

- случайный трек из `music`
- случайная перебивка из `interruptions`
- снова случайный трек из `music`
- снова случайная перебивка из `interruptions`
- и так бесконечно

## Что есть

- авто-попытка запуска при открытии сайта
- fallback на первый клик / клавишу, если браузер заблокировал autoplay
- без видимого плеера и без кнопок перемотки
- отображение названия текущего файла без расширения
- туман и центральное ядро, которые реагируют на громкость музыки
- поддержка популярных расширений: `mp3`, `ogg`, `wav`, `m4a`, `aac`, `mp4`, `webm`, `flac`, `opus`

## Как пользоваться

### 1. Закинуть файлы

Положи музыкальные треки в папку `music`, а перебивки — в папку `interruptions`.

Можно использовать обычные названия файлов, включая пробелы и кириллицу.

### 2. Обновить manifest.json

Браузер сам не умеет читать список файлов в папке на статическом сайте. Поэтому нужно обновлять манифесты.

Запусти:

```bash
node scripts/generate-manifest.mjs
```

После этого обновятся:

- `music/manifest.json`
- `interruptions/manifest.json`

### 3. Запустить сайт

Желательно через локальный сервер.

Примеры:

```bash
python -m http.server 8000
```

или

```bash
npx serve .
```

Потом открой сайт в браузере.

## Важно

### Про autoplay

Сайт **пытается** стартовать сам сразу. Но некоторые браузеры блокируют автозапуск аудио со звуком. В таком случае достаточно **один раз кликнуть в любое место сайта**.

### Про форматы

Поддержка зависит не только от расширения файла, но и от кодека внутри. Если какой-то файл не играет, попробуй перекодировать его в `mp3` или `ogg`.
